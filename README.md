# Atlas — מילון מדינות העולם

גרסת המקור של יישום **Atlas Countries** המופעלת ב‑Vercel.

## מה יש ביישום

- 197 מדינות
- חיפוש בעברית ובאנגלית
- סינון לפי יבשות
- דגלי מדינות
- תמיכה בהתקנה כ‑PWA
- Service Worker ושימוש לא מקוון בקובצי הליבה
- ממשק RTL נגיש ורספונסיבי

## מקורות

- נתוני מדינות: `mledoze/countries` — ODbL
- שמות בעברית: Unicode CLDR / `Intl.DisplayNames`
- דגלים: `lipis/flag-icons` — MIT

## Vercel

הגרסה החיה: `atlas-countries-nu.vercel.app`
